## 一、项目概述

### 1.1 项目定位

基于 **LangGraph** 框架 + **FastAPI** + **Vue 3** 构建的**交互式对话驱动**多 Agent 协作小说创作系统。

- **对内**：多个专职 Agent（世界观构建、剧情推进、剧情质控、整合输出）协作完成内容生成
- **对外**：Web 前端 + SSE 流式输出，用户通过**选择选项**或**自由输入**参与每一步剧情推进

### 1.2 核心理念

```
传统模式：用户输入需求 → AI 一次性生成完整小说 → 用户被动阅读

本项目：  用户输入需求 → AI 构建世界观 → 用户确认
          → AI 生成剧情片段 + 选项 → 用户选择/输入
          → AI 生成下一片段 + 选项 → 用户选择/输入 → ... 循环
          → 用户请求结束 → 整合输出完整小说

用户是"导演"，AI 是"编剧团队"
```

### 1.3 核心功能一览

| 功能                          | 说明                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| **交互式剧情推进**      | 每轮生成 200-500 字剧情片段 + 2-4 个选项，用户选择或自由输入 |
| **多 Agent 协作**       | 5 个专职 Agent 内部协作，用户无感知                          |
| **内部质控 + 人工审核** | Critic 自动审查，低分时中断请求用户确认（通过/驳回重写）     |
| **SSE 流式输出**        | 逐 token 实时渲染到前端，打字机效果                          |
| **回溯**                | 基于 segment_history 回到上一步，重新选择                    |
| **续写**                | 已完成创作可基于长期记忆续写新剧情                           |
| **多会话管理**          | 创建/切换/重命名/删除会话，独立进度                          |
| **整合输出**            | 所有片段润色为完整小说                                       |

## 二、交互模式设计

### 2.1 交互流程总览

```
用户输入创作需求
        │
        ▼
┌─────────────────────────────────────┐
│  WorldBuilder（世界观构建）           │
│  - 调用 Bing 搜索收集背景资料         │
│  - 生成世界观设定、角色、规则          │
│  - 进入 Critic 审查                  │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Critic（设定审查）                   │
│  - 评分低于阈值 → 中断等用户确认      │
│  - 用户批准 → 进入剧情推进            │
│  - 用户驳回 → 重构建世界观            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  StoryDriver（剧情推进）              │
│  - 参考记忆、RAG 素材、历史上下文      │
│  - 生成剧情片段 + 2-4 个选项          │
│  - 进入 Critic 审查                  │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Critic（剧情审查）                   │
│  - 评分低于阈值 → 中断请求用户确认     │
│  - 用户批准 → 展示给用户选择          │
│  - 用户驳回 → 重写剧情               │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Supervisor（等待用户输入）            │
│  - 展示剧情 + 选项                    │
│  - interrupt() 暂停，等用户响应       │
│  - 用户选择/输入 → 下一轮             │
└──────────────┬──────────────────────┘
               ▼
        ... 循环推进 ...
               │ 用户输入"生成全文"或"结束"
               ▼
┌─────────────────────────────────────┐
│  Integrator（整合输出）               │
│  - 拼接所有片段，润色为完整小说        │
│  - 保存长期记忆（支持续写）            │
└─────────────────────────────────────┘
```

### 2.2 交互类型

| 类型               | 用户操作                         | 系统行为                    |
| ------------------ | -------------------------------- | --------------------------- |
| **选择选项** | 输入 A/B/C/D 或点击选项按钮      | 按选中方向推进剧情          |
| **自由输入** | 输入任意文本                     | 解析意图，融入剧情推进      |
| **回溯**     | 点击"回退"按钮或输入"回到上一步" | 从 segment_history 回退一轮 |
| **结束**     | 输入"生成全文"或"结束"           | 触发 Integrator 节点        |
| **人工审核** | 通过/驳回 + 修改意见             | 通过则放行，驳回则重写      |

### 2.3 选项设计原则

| 原则               | 说明                                        |
| ------------------ | ------------------------------------------- |
| **数量控制** | 每轮 2-4 个选项（含 1 个自由输入兜底项）    |
| **差异明显** | 选项之间方向差异显著（战斗/对话/探索/逃避） |
| **后果暗示** | 选项附带 hint 和 risk_level 标注            |
| **始终兜底** | 用户可自由输入而不选择选项                  |

### 3.3 节点间数据流

```
用户输入 ──► Supervisor（解析意图、路由）
Supervisor ──(user_request)──► WorldBuilder
WorldBuilder ──(world_setting, characters, rules)──► Critic
Critic（设定审查通过）──► Supervisor（进入剧情推进）
Supervisor ──► StoryDriver（生成剧情 + 选项）
StoryDriver ──(segment, options)──► Critic
Critic（剧情审查通过）──► Supervisor（展示给用户 + interrupt 等待）
Supervisor ──(用户选择)──► StoryDriver（下一轮）
... 循环 ...
用户输入"生成全文" ──► Supervisor ──► Integrator（润色输出）
```

### 3.4 条件路由

**supervisor_route — 从 supervisor 出发的路由决策：**

| 当前阶段              | 条件                             | 下一节点                         |
| --------------------- | -------------------------------- | -------------------------------- |
| `init`              | —                               | `world_builder`                |
| `world_building`    | 未生成世界观                     | `world_builder`                |
| `world_building`    | 已生成世界观，未确认             | `supervisor`（暂停确认）       |
| `world_building`    | 已确认                           | `story_driver`                 |
| `story_progressing` | 等待用户输入 (`awaiting_user`) | `supervisor`（interrupt 暂停） |
| `story_progressing` | 已收到用户输入                   | `story_driver`                 |
| `critic_loop`       | 用户驳回                         | `story_driver`                 |
| `critic_loop`       | 未驳回                           | `critic`                       |
| `completed`         | —                               | `integrator`                   |
| `done`              | —                               | `END`                          |

**critic_route — 从 critic 出发的路由决策：**

| 审查类型 | 条件                  | 下一节点                     |
| -------- | --------------------- | ---------------------------- |
| 设定审查 | 未通过（critic_loop） | `world_builder`（重构建）  |
| 设定审查 | 通过                  | `story_driver`（进入剧情） |
| 剧情审查 | 未通过（critic_loop） | `story_driver`（重写）     |
| 剧情审查 | 通过                  | `supervisor`（展示给用户） |

### 4.1 状态结构

```python
class NovelState(TypedDict):
    # ---- 用户输入 ----
    user_request: str                # 用户初始创作需求

    # ---- 世界观设定 ----
    world_setting: str               # 世界观文本
    characters: List[dict]           # 角色列表 [{name, role, personality, description}]
    rules: str                       # 核心规则
    setting_confirmed: bool          # 用户是否确认设定

    # ---- 剧情 ----
    story_segments: List[str]        # 所有剧情片段（累积式）
    current_segment: str             # 最新生成的片段
    plot_version: int                # 剧情版本号
    segment_history: List[dict]      # 历史记录 [turn, segment, options]（用于回溯）

    # ---- 交互 ----
    current_options: List[dict]      # 当前选项 [{id, text, hint, risk_level}]
    user_choices: List[dict]         # 用户选择记录 [{turn_id, choice_type, content, selected_option}]
    current_turn: int                # 当前轮次
    awaiting_user: bool              # 是否在等待用户输入

    # ---- 质控 ----
    critique: str                    # 审查意见
    critique_score: int              # 审查评分
    risk_warnings: List[str]         # 风险警告

    # ---- 输出 ----
    final_output: str                # 完整小说

    # ---- 记忆 ----
    memory: MemoryState              # 故事记忆（角色/线索/伏笔/时间线）

    # ---- 消息 ----

    # ---- 人工审核 ----
    human_approval: Optional[str]    # pending / approved / rejected
```

**输入解析逻辑：**

```python
def parse_user_input(user_input, phase):
    # 特殊指令（优先级最高）
    if user_input in ("生成全文", "结束"):
        return {"action": "generate_full"}
    if user_input in ("回到上一步", "回溯"):
        return {"action": "backtrack"}
    # 阶段特殊指令
    if phase == "world_building" and user_input.upper() == "A":
        return {"action": "confirm_setting"}
    if phase == "world_building" and user_input.upper() == "B":
        return {"action": "modify_setting"}
    # 通用选项
    if user_input.upper() in ("A", "B", "C", "D"):
        return {"action": "select_option", "selected_option": ...}
    # 关键词规则匹配
    COMMON_RULES = [
        (r"继续|然后呢", {"action": "select_option", "selected_option": "A"}),
        (r"不行|换一个|重来", {"action": "backtrack"}),
        (r"确认|可以|就这样", {"action": "free_input"}),
        ...
    ]
    # 兜底：LLM 解析
    return {"action": "free_input"}
```

### 6.3 回溯机制

```python
def handle_backtrack(state):
    segment_history = state.get("segment_history", [])
    if not segment_history or state["current_turn"] <= 1:
        return  # 无可回溯内容

    steps_used = len(segment_history)
    if steps_used >= MAX_BACKTRACK_STEPS:
        return  # 达到回溯上限

    # 弹出最后一段
    last_item = segment_history.pop()
    segments = list(state["story_segments"])
    if segments:
        segments.pop()

    return {
        "segment_history": segment_history,
        "story_segments": segments,
        "current_segment": segment_history[-1]["segment"],
        "current_options": segment_history[-1]["options"],
        "current_turn": state["current_turn"] - 1,
        "current_phase": "story_progressing",
        "awaiting_user": True,
    }
```

## 七、API 接口

### 7.1 接口列表

| 方法       | 路径                                     | 说明                                            |
| ---------- | ---------------------------------------- | ----------------------------------------------- |
| `POST`   | `/api/sessions`                        | 创建新会话：接收`user_request`，启动图        |
| `POST`   | `/api/sessions/{id}/action`            | 发送用户操作：`Command(resume=action)` 恢复图 |
| `GET`    | `/api/sessions/{id}`                   | 获取会话当前状态                                |
| `GET`    | `/api/sessions`                        | 列出全部会话元数据（进度摘要）                  |
| `PATCH`  | `/api/sessions/{id}`                   | 更新会话标题                                    |
| `DELETE` | `/api/sessions/{id}`                   | 删除会话元数据                                  |
| `GET`    | `/api/sessions/{id}/stream?action=...` | **SSE 流式**：逐 token 推送图执行事件     |
| `POST`   | `/api/sessions/{id}/resume`            | 基于长期记忆续写新会话                          |
| `GET`    | `/api/memories`                        | 获取所有长期记忆列表                            |
| `GET`    | `/api/memories/{memory_id}`            | 获取单条长期记忆详情                            |

### 7.2 SSE 流式事件类型

| 事件类型       | 含义                   | 数据字段                             |
| -------------- | ---------------------- | ------------------------------------ |
| `node_start` | 某节点开始执行         | `node`, `input`                  |
| `node_end`   | 节点执行完成           | `node`, `output`（关键状态字段） |
| `token`      | LLM token 片段         | `node`, `content`                |
| `interrupt`  | 图在中断处暂停         | `data`（interrupt payload）        |
| `error`      | 节点执行错误           | `node`, `error`                  |
| `final`      | 流结束后的完整状态快照 | 完整`SessionResponse`              |
| `done`       | 流结束                 | `message`                          |

### 7.3 响应模型 (SessionResponse)

```json
{
  "session_id": "uuid",
  "phase": "story_progressing",
  "turn": 3,
  "segment": "最新剧情片段文本",

  "world_setting": "世界观文本",
  "characters": [{ "name": "角色名", "role": "角色", "personality": "性格" }],
  "rules": "核心规则",
  "critique": "审查意见",
  "risk_warnings": ["风险警告"],
  "final_output": "完整小说（仅完成时）",
  "human_approval": null,
  "error": ""
}
```

## 八、SSE 流式输出 — `src/utils/streaming.py`

### 8.1 流式执行流程

```
前端调用 GET /api/sessions/{id}/stream?action=用户输入
  → 后端调用 graph.astream_events(Command(resume=action), config, version="v2")
  → transform_graph_events 实时转换事件
  → 逐 event 推送 SSE
  → 后端获取最终状态
  → 推送 final 事件（完整快照）
  → 推送 done 事件（结束）
```

### 8.2 事件转换逻辑

| LangGraph 事件           | SSE 事件       | 说明                              |
| ------------------------ | -------------- | --------------------------------- |
| `on_chain_start`       | `node_start` | 记录`current_node`，推送节点名  |
| `on_chain_end`         | `node_end`   | 过滤关键字段推送                  |
| `on_chat_model_stream` | `token`      | 推送`current_node` + token 内容 |
| `on_chain_error`       | `error`      | 推送错误信息                      |
| `on_custom_event`      | `interrupt`  | 推送中断数据                      |

## 九、工具体系

### 9.1 记忆工具 — `src/tools/memory.py`

**MemoryState 结构：**

| 字段              | 类型                      | 说明                                       |
| ----------------- | ------------------------- | ------------------------------------------ |
| `characters`    | `List[CharacterMemory]` | 角色记忆（性格、关系、弧线、最后出现轮次） |
| `plot_threads`  | `List[PlotThread]`      | 剧情线索（active / resolved / abandoned）  |
| `foreshadowing` | `List[Foreshadowing]`   | 伏笔（pending / fulfilled）                |
| `timeline`      | `List[str]`             | 关键事件时间线                             |
| `world_notes`   | `List[str]`             | 世界观细节笔记                             |

**滑动窗口裁剪：**

- 角色：仅保留最近 5 轮内出现过的
- 伏笔：仅保留最近 10 条待回收伏笔
- 时间线：仅展示最近 5 个事件

**记忆更新流程：**

1. `story_driver_node` 生成新剧情片段
2. LLM 分析片段，提取记忆更新（`memory_updates`）
3. `_apply_updates` 合并到 `MemoryState`

### 9.2 RAG 工具 — `src/tools/rag_tool.py`

| 步骤 | 组件              | 说明                                 |
| ---- | ----------------- | ------------------------------------ |
| 1    | ChromaDB 向量检索 | 检索 k=20 条候选                     |
| 2    | Reranker 重排序   | SiliconFlow bge-reranker，保留 top 5 |
| 3    | TTL 缓存          | 300 秒进程内缓存                     |

### 9.3 搜索工具 — `src/tools/search_tool.py`

- 基于 Bing MCP 服务（`bing-cn-mcp-enhanced`）
- 支持 `streamable_http`（云端）和 `stdio`（本地 npx）
- 未配置时安全返回空字符串

### 9.4 文档工具 — `src/tools/document_util.py`

- 支持 txt / md / pdf / docx / csv 格式
- `RecursiveCharacterTextSplitter`（chunk_size=200, overlap=20）
- 将 `knowledge_base/` 文档入库到 ChromaDB

### 9.5 长期记忆 — `src/tools/long_term_memory.py`

- 基于 SQLite 存储
- 保存完整上下文（世界观、角色、规则、剧情片段、记忆状态、最终成稿）
- 用于"续写"功能：从长期记忆恢复状态，生成新 `session_id` 继续推进

